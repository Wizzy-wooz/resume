# Olena Vodzianova · Resume

A responsive, accessible resume website based on the supplied PDF.

**GitHub Pages:** https://wizzy-wooz.github.io/resume/

## Preview locally

Run `python3 -m http.server 8000` in this directory and open http://localhost:8000.

## Edit

- `index.html`: resume content and links
- `styles.css`: responsive layout, colors, typography, and print styles
- `Oleva_Vodzianova_Data_Engineer_resume.pdf`: downloadable original resume

No build step or dependencies are required. GitHub Pages serves the repository root from the `main` branch. Google Fonts are optional; local fallback fonts work without network access.
